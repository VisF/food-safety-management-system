🔄 FLUJOS IMPLEMENTADOS
═══════════════════════════════════════════════════════════════════════════

  1. Inscripción a Curso Presencial
     Usuario → InscripcionControlador → DocumentoControlador 
           → ValidacionControlador → ExamenControlador → TramiteControlador

  2. Búsqueda por DNI (Inspector)
     Inspector → InspectorControlador → UsuarioModelo → CarnetModelo 
            → TramiteControlador → AuditoriaAccionesModelo

  3. Exportación a DIPA
     Admin → DipaControlador → InscripcionModelo → ResultadoExamenModelo 
         → GenerarArchivoExportacion()

  4. Evaluación de Examen
     Admin → ExamenControlador → ResultadoExamenModelo → ValidacionControlador 
         → TramiteControlador → NotificacionControlador

  5. Carga de Documentación
     Usuario → DocumentoControlador → UploadControlador → DocumentoModelo 
           → NotificacionControlador
