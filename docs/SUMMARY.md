# Documentación del proyecto — Resumen

Esta carpeta `docs/` centraliza la documentación del proyecto. A continuación un resumen rápido de los archivos disponibles y su propósito.

- `ARQUITECTURA_COMPLETADA.md` — Documento técnico con la descripción completa de la arquitectura MVC, listado de modelos y controladores, y flujos principales.
- `MAPEO_VISTAS_CONTROLADORES.md` — Mapeo detallado de cada vista a su(s) controlador(es) correspondiente(s) y ejemplos de integración.
- `RESUMEN_PROYECTO.md` — Resumen ejecutivo para gestores: estado del proyecto, métricas y próximos pasos.
- `VERIFICACION_FINAL.md` — Revisión y verificación de cada componente (modelos, controladores, métodos).
- `README_PROJECT.md` — README completo del proyecto (versión larga), movido desde la raíz.
- `FASE_3D_DOCUMENTACION.md` — Notas de la fase 3D (creación de controladores y decisiones clave).

Cómo empezar:

1. Leer `RESUMEN_PROYECTO.md` para el panorama general.
2. Leer `ARQUITECTURA_COMPLETADA.md` si vas a trabajar en código (modelo/controlador).
3. Consultar `MAPEO_VISTAS_CONTROLADORES.md` para integrar vistas.

Contacto: ver `contexto.txt` para roles y objetivos del proyecto.
